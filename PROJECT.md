# Project

## Goal

Build a generic B2B automation platform that can be adapted to different clients mainly through configuration and integrations, rather than client-specific rewrites.

## Principles

- Keep the generic core separate from client-specific logic.
- Prefer simple, modular components with clear interfaces.
- Do not introduce complexity before it is needed.
- Reliability, security, auditability and testability are first-class concerns.
- The repository, documentation and tests are the source of truth; Codex conversations are temporary.

## Current scope

Only define and build the smallest useful foundation. No production feature exists yet.
